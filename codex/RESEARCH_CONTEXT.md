# Research handoff context

Purpose: build a reproducible data-driven BTC futures research repository from a sequence of analyses previously performed in ChatGPT.

The user wants candle-by-candle empirical discovery, especially repeating tendencies by New York weekday/time and multi-candle shape. Traditional predefined technical rules are secondary. The later research also asked for an institutional trader's perspective: market structure, reference-level interactions, volatility regime, session openings and executions.

Study periods: source file roughly 2025-12-31 through 2026-08-01 UTC; analyses concentrated Jan–Jul 2026. Timeframes: 5m/15m/30m; observations are research snapshots, not independently audited tradeable strategies.

The key validated *type* of finding is scheduled volatility concentration around US opening and Sunday evening, not deterministic candle color or confirmed institutional positioning. Treat all directional findings as hypotheses.

Data lacks order book, funding, market/mark prices, open interest and liquidation feeds. New versions should store exact input hash, code revision, parameter grid, discovery/test split and counterfactual baseline.
