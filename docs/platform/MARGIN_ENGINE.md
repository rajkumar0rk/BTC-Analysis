# M5 reference venue-risk simulation

M5 adds an opt-in fixed-tier linear single-instrument model, integrated with the existing event engine. The original 1x reference path remains available. No real order submission. This is not an exchange-certified liquidation or margin implementation.

## Configuration and provenance
MarginProfile requires instrument identity, effective interval, source, minimum initial-margin rate, maintenance rate, maximum supported notional, liquidation fee bps and (if enabled) a settlement interval/anchor. The caller must provide independently reviewed historical parameters and evidence. Do not take a current spec and backfill it across historical periods. The profile SHA-256 is stored in each result. A leverage request must respect the initial-rate floor. Portfolio margin, spread, tier transitions and inverse/multi-currency contracts are rejected or out of scope. The engine consumes a RiskBar per execution candle with identical mark interval and an explicit FundingSettlement at each required boundary. Pinned mark/funding manifest hashes must match configuration; observed risk streams are hashed and compared across scenarios. Missing, extra, or misaligned inputs fail. Hourly funding OHLC candles alone do not prove actual settlement events. This module does not convert them to settlements or attest real exchange data.

## Semantics
- Same-account currency linear contracts. Cross: collateral equity = balance + mark unrealized P&L. Isolated: fixed allocated entry margin (FIFO lots) plus position funding adjustments and mark unrealized P&L. Partial closes release allocated margin and proportional funding adjustment. Cash balance includes actual simulated realized P&L, fees, taxes and signed funding. Entry checks free isolated wallet or cross collateral against required initial margin and fixed notional ceiling. No pending-order margin reservation or mark-dependent tier schedule.
- Funding settles before eligible open orders, signed quantity times supplied settlement mark times rate; long pays when positive. Funding is booked to the account and current trade, including open-trade funding. Require exact supplied boundary event even when flat.
- At open and each paired path vertex, update mark and check maintenance; mark-first before trade movement is a stress assumption, not synchronized tick truth. At each modeled fill, recheck using current mark. Breach forces modeled full reduce-only close at mark with configured slippage and liquidation fee + tax, cancels orders, and halts new strategy orders. A deficit remains visible; no artificial insurance credit, isolated loss cap or actual exchange liquidation price claim. No partial liquidation, ADL, insurance accounting, warning or true exchange queue simulation.
- Equity, drawdown, monthly marks use supplied mark prices in risk mode. Trade fills still use trade OHLC paths. No interpolation of joint mark/trade events. Liquidation counts and separate funding records are emitted; closed trade and account cost reconciliation include signed funding.

## M44 observed spread calibration
Publish bounded BTCUSD Delta L2 receipt-time samples with source hashes, reject invalid/crossed/slow books and conflicting receipts. Browser cutoff excludes receipts at/after date; minimum ten samples and median/p90/maximum observed half-spread bps. Explicit operator acknowledgement applies the chosen fixed half-spread plus additional impact to the shared existing slippage input; no silent changes. Fees, GST and risk settings remain unchanged. Earlier dates may use a retrospective stress assumption only, not causal calibration. No tick replay, depth/queue model, ETH calibration, actual fills, or guaranteed chronological selection for imported data. Exact numeric slippage is stored in ordinary run settings; calibration provenance itself is not persisted in run records. Sparse source snapshots cannot supply continuous historical bid-ask data.

## M45 whole-notional bracket research model
Opt-in tiered profile (1–32 ordered inclusive notional caps, nondecreasing initial/maintenance rates, first tier matches base fields, last cap equals max_notional). All tiers share explicit effective dates and source; no venue rates assumed. Existing fixed-tier profile schema remains unchanged. Entry validates requested leverage against projected bracket, isolated entry-cost basis is re-rated when lots change, cross checks aggregate initial margin. Maintenance re-rates at every modeled mark event; adverse buffer evaluates bracket at projected adverse mark within cap. Positions beyond supplied cap fail closed; no extrapolation. Whole-position rate jumps are conservative assumptions, not exchange-specific incremental/deduction or partial-liquidation rules. Short and continuous replay accept optional tier JSON; profile hash identifies rates. Tests cover boundaries, rejection, short transition liquidation, deterministic results and cap failure. Actual historical tier schedules, partial liquidation and portfolio margin remain unverified.

## M46a single-position portfolio-style stress reference
Delta's [portfolio margin guide](https://guides.delta.exchange/delta-exchange-india-user-guide/trading-guide/margin-explainer/portfolio-margin) describes portfolio-wide stress tests and liquidation using risk reduction/position scaling. This explicit opt-in research subset is **not the Delta portfolio engine**. One unhedged linear perpetual only; account collateral equals wallet plus mark unrealized P&L. For symmetric up/down price shocks, worst standalone price loss is notional times shock. Initial requirement is max(base floor, initial shock, reciprocal leverage) times notional; maintenance max(base maintenance floor, maintenance shock) times notional. Explicit dated source, shock inputs, leverage limit and cap; no tier combination. Pre-liquidation buffer uses adverse price stress within supported cap. Full modeled liquidation and halt retained. Fixed/tiered profiles reject portfolio mode; stress profile rejects isolated/cross. No multi-position offsets, options, hedge orders, liquidation sizing or order reservation. Both short and long replay use the shared adapter. Actual historical venue stress parameters and liquidation rules remain unverified.
