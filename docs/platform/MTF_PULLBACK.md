# Standalone strategy source files (not application features)

The dedicated Touch/Reclaim runtime, exact-source recognition, and Cloud template buttons were removed. The two files in `strategies/cloud/` are optional user-authored source examples, **not imported, registered, published as frontend assets or executed automatically**. To use either, copy its plain Python text into a new Cloud Python strategy and save. The same restricted generic SDK interpreter handles every compatible handwritten script. Change indicators, warmup, trading conditions, exposure or bracket distances in the source; no application code changes or deployment needed. Old saved wrappers, if any, import a removed implementation; replace their source with the corresponding ordinary script in a new immutable revision. Existing stored revisions are not automatically changed.

The scripts use 1H/15M Supertrend ATR10 × 3, 15M EMA20, Touch on completed 1m and Reclaim on completed 15m, next-minute open, 100h initialization, IST weekday entries, all-day exits, one filled entry per contiguous aligned cycle, no overlapping positions, fixed 100/200-point brackets, no trailing/reversal exit. Generic fixed-point bracket protection remains active during the entry minute; modeled slippage, gaps and liquidation/pre-liq can change realized exits. Exposure default 50%, editable. No historical parity or production trading claim. No special-case optimizer integration.
