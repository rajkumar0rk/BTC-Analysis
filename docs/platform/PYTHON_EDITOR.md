# M8 advanced Python editor

Local Strategy Studio uses Monaco with bundled Python tokenization, SDK completions, line markers, keyboard completion, and plain-text fallback. The SDK catalog is served by the authenticated backend from the actual M4 indicator definitions. Source byte count is explicit. Validate syntax before saving a new immutable version; previously stored versions remain readable and unchanged. Stale validation disappears on edits. The API registry still accepts inert drafts, so this UI gate is not a security boundary.

POST /v1/strategies/validate accepts UTF-8 source up to 64 KiB and returns its SHA-256, Python version, syntax_valid, diagnostics and execution_allowed=false. Compiler runs in an isolated-mode Python subprocess with scrubbed environment, CPU/address-space/wall limits and two concurrent slots per API process; it compiles only and never evaluates bytecode. GET /v1/sdk/catalog returns actual supported indicator names/defaults/outputs. Both routes require authentication. No arbitrary source is imported, evaluated or scheduled. This is not an untrusted-code execution sandbox.

Monaco suggestions are curated SDK snippets, not a full Python language server or semantic/type checker. Syntax validity does not prove correct strategy logic, availability of referenced indicators, safety or profitability. Tests cover inert code, syntax/scope diagnostics, byte quota and authorization; browser test covers Monaco initialization, plain-text mode, diagnostics and immutable saves through the actual API. No public deployment. Dependency lockfile, production review and arbitrary execution remain separate gates.
