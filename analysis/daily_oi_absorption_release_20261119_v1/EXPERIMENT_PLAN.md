# Pre-registered BTC-first OI absorption release
Economic mechanism: rising open interest while price is compressed may represent accumulated inventory/latent leverage; a subsequent close beyond the previous 60-minute high/low could trigger directional forced hedging and continuation. This is distinct from OI deleveraging or OI/mark premium fading; falsify if no BTC after-cost persistence.
Selection: BTCUSD only, frozen before ETH validation. 5-minute OI growth >=2% versus 60min prior; preceding 60min range <=0.8%; completed 5min close exceeds preceding 60min high/low; entry next 1m open (five minutes after 5m candle start). OI values delayed an extra 5min to mitigate unknown timestamp semantics. 01:00-21:00 UTC signals, one position/calendar day, $1000 unlevered notional on $1000 equity, no averaging, 0.35% SL, 0.70% TP, max 90 minutes, stop-first. BTC 2025 fixed discovery rules, BTC 2026 robustness with no retuning; exact same dimensionless rules applied to ETH afterward as secondary validation, never used to select settings.
Conservative modeled taker fees+18% GST 0.118% roundtrip, slippage 0.04% roundtrip, stress 0.238%. Funding assumed zero for <=90min and unverified; bid/ask, min contract, liquidation and funding settlement unverified. Positive result is INCONCLUSIVE until execution verified. Include every calendar day and gap day, year/month summaries, risk/cost decomposition, source hashes.
Data quality: all minute bars must be dense, OI source provenance hashed. This is a feasibility study, NOT executable proof. No modification to main or other research.
