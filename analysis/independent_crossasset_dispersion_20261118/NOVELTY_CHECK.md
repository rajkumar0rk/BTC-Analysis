# Pre-run novelty gate — cross-asset normalized 4H return dispersion

Decision: **PARTIAL OVERLAP — approved differential**, not a novel underlying candle setup.

Compared against `codex/STRATEGY_NOVELTY_GATE.md`, `scripts/research_independent_crossasset_confirmation_20261118.py` on research/independent-crossasset-confirmation-pf-20261118, `scripts/research_btc_eth_profit_factor_pairs.py`, `scripts/eth_native_crossfamily_v2.py`, and recent directional entropy / volatility balance branches. Those studies test directional agreement, trend filters, standalone base families, directional entropy and volatility balance; none of these specific previously checked scripts tests **the cross-market dispersion in standardized, completed 4H log returns** conditioned on a base signal. Novelty is limited to the dispersion filter; do not claim new base entries.

**Rules fixed before results:** retain the same three previously audited families (4H engulfing reversal, 15m trend retest, 1H failed auction), identical on BTC and ETH. For each signal at the signal bar's completion, compute the latest fully completed 4H log-return (close/previous close) for both assets, each divided by its own 20-bar 4H rolling standard deviation of *previous* 4H log returns (shift 1). Compute own-minus-other standardized return. Filter in two predeclared modes: (1) **leader**: long if own-minus-other >= +0.75, short if <= -0.75; (2) **laggard**: long if own-minus-other <= -0.75, short if >= +0.75. These are relative leadership/laggard hypotheses, not other-asset direction agreement. Only fully closed, valid 4H candles are used, no future returns. Original family signals must also pass. Enter at next available 1m open; ATR stop 1.5/2.5, target 2R/3R, maximum holds 12h for 15m, 24h for 1h, 72h for 4h. 1m conservative stop-first and gap-aware exits, one open position, 0.5% account risk per stop capped at 3x notional. Fee 0.05% each side +18% GST, BTC adverse slip 5 points per side, ETH adverse slip 0.02%/side. Use same rule parameters for both coins. 2025-only ranking, 2026 exposed historical check (not virgin OOS). Monthly net PF and equity-based net return, plus 2025 complete calendar and 2026 Jan-Oct YTD, no annualizing. Nov2026 excluded.

**Data quality:** Native original Delta India BTC and ETH 1m loader must verify UTC manifest hashes and repaired BTC 2026-10-31 partition; Jan 2025 IST first 5.5h absent. Funding, real spread, impact, margin/liquidation, lot size and real fills not modeled. Cross-asset signal may be highly correlated, and low sample counts are a key failure mode.

Only this new branch/folder is modified. No live trading and no changes to other automation schedules.
