# Step 22 — Causal supervised LONG/SHORT prediction at frozen entry times

**Novelty gate: PARTIAL OVERLAP, approved differential.** This is a new *supervised direct sign-of-counterfactual-outcome* test, not a newly invented price-action feature or verified signal. Step 6 used a hand-built online event return comparison, Step 8 used nearest neighbors of preentry OHLC features, Step 11 dynamically selected six indicator arms from previous fallback outcomes, and Steps 16–21 fit exits on the repeatedly researched same candles. This test holds all times/exits fixed and trains a **regularized supervised regression or logistic classifier for LONG-versus-SHORT** from strictly prior completed trading days' shadow outcome differences. It must be reported as exploratory because 2025–2026 was already searched.

## Frozen supervised study grid
At each original day's preentry timestamp, calculate ONLY previous completed minute OHLCV features:
- last completed 5m,15m,60m,240m signed price returns normalized by fixed typical scales;
- completed 5m relative volume to preceding20 nonoverlapping 5m bars;
- prior60m rolling high-low range fraction and location of last completed close;
- prior SMA20 vs SMA60 close gap;
- 14m ratio of average up/down 1m close returns (RSI-like);
- completed 15m realized range / price.
No same-day realized return, intrabar current candle or future trade result can enter any feature.
Two feature sets: `basic` = 5m/15m/60m/240m returns + RVOL + prior60m price-location; `context` = all ten above.
Training labels: each PREVIOUS completed day has both LONG and SHORT hypothetical net returns calculated on the same 1m OHLC using original E no-added-early-exit policy (stop/TP/nextbar trail) and each hypothetical side's own preentry risk caps. Difference `LONG net−SHORT net` is known only after that prior day's 30m horizon elapsed. For supervised model, the label is positive if LONG would have had a higher modeled net than SHORT. These are historical counterfactuals, not exchange-executed observations; report simulation/model limitation.
- Model algorithms: **Ridge regression (L2 alpha=10) of basis-point LONG−SHORT return** and **L2 logistic regression (C=0.25, liblinear)** of LONG wins vs SHORT, standardized on only previous training window.
- Training pool: previous completed **same entry type** (volume event vs mandatory fallback) weekday samples, last **60/120/240** examples, at least 40 previous type-matched observations. Fit again at each day using no outcomes of current day or later days. History runs chronologically across 2025–2026 as an online learner, with settings chosen on 2025 only.
- Candidate scope: replace side if high-confidence ML side differs from existing Step11 baseline for `event only`, `fallback only`, or `both`.
- Model override confidence: predicted standardized score magnitude ≥ **0.10,0.20,0.30** for Ridge (fitted bp forecast divided by std of previous bps), or |2×logistic_p_long−1| ≥ same three thresholds; otherwise keep original side. Always one real 1m OPEN order even if model cold-start/no-confidence.
**2 algorithms ×3 history windows ×2 feature sets ×3 confidence levels ×3 scopes =108 fixed alternatives plus unchanged baseline =109 models, 218 cost scenarios.** No added stop/timing or 2026-specific param changes.
- For each model precompute both possible direction-specific 1m exit arrays. Choose one actual side each calendar date using only model predicted preentry info. Update monthly equity state using only previous COMPLETED chosen actual results (same as Step15 B). Recompute stop caps for LONG versus SHORT properly. Standard fees are repriced on SAME selected directions/exits (do not train separate standard-fee classifier), one trade on all 477 weekdays.
- Require exact full daily baseline parity with historical Step20 B, 477 weekday dates and no weekend sessions.
- **2025-only selection**: require >=12/12 profitable months in 2025 (vs B 11), 2025 net >= B 2025 +8.882867%, 2025 profitable days>= B 153, 2025 DD <= B 2.617670%. Rank eligible by 2025 profitable-month count, then 2025 net, then win days, then lower DD. If none, retain original B baseline (this constitutes a failed monthly improvement). Evaluate frozen settings on Jan–Oct2026, which has been previously researched and **is not a genuinely independent blind holdout**; promotion requires >=22/22 profitable months, net >=25.423847%, DD<=2.617670%, all 477 trades, and no loss of 2026 positive months or net.
