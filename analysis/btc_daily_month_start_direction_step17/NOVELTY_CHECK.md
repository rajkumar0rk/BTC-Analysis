## Exact predeclared general month-start direction policies
Only on the **first 2,5,8 full eligible trading weekdays** of EVERY calendar IST month, optionally change the already-selected entry side. Scope is EITHER `fallback` (21h entries only) OR `both` (vol-event + fallback). One of 7 frozen pre-entry rules:
1. `invert_existing`: opposite original side with no additional filter.
2. `follow60`: follow previous complete 60-minute signed return if absolute return>=0.20%, otherwise original side.
3. `fade60`: oppose previous 60m move if abs return>=0.20%, else original.
4. `follow240`: follow previous 240m return if abs>=0.40%, else original.
5. `fade240`: oppose previous 240m move if abs>=0.40%, else original.
6. `edge60_follow`: if last completed 1m close lies in upper 20% of prior 60m high-low range, enter LONG; lower20%, SHORT; else original.
7. `edge60_fade`: reverse upper/lower edge 60m direction; otherwise original.
Preentry features use only completed 1m OPEN/CLOSE/HIGH/LOW at or before `entry_timestamp−1 minute`. 60m/240m historical opens and rolling range ending at t−1; no current candle, no future daily PnL, no prior hindsight-specific January exceptions. Do not change exit policy timing, stop or target. Base selected side is fully causal prior completed days; new side is fixed deterministic pre-entry feature.
