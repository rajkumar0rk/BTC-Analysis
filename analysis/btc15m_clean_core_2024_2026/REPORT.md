# BTCUSD 15m core-only backtest

EMA20 reclaim within 4 completed candles following Supertrend(10,3) interaction. One position per cycle; next minute entry. Fixed SL3%, TP9%; no ST flip exit. No ATR/EMA slope/RSI filter, monthly guard, adaptive stops/locks, drawdown sizing, loss sizing, scale-in/out or hedging. Fixed 80% or 100% of equity notional.

Starting equity $1000 independently each period; fee 0.05% per side + GST18%, slip 0.02% per side; funding not modeled. 2024 Sep-Dec only, August warmup. 2025-2026 same archive as previous research.
